# @nexode/types

Shared TypeScript types for the NeXoDe platform.

## Classification

Foundation Package

## Responsibilities

- Shared TypeScript types
- Shared interfaces
- Utility types
- Branded types
- Common platform contracts

## Non-Responsibilities

- Business logic
- Runtime code
- Configuration
- Database access
- Network requests
- Environment loading

## Public API

```ts
import {} from '@nexode/types';
```

## Allowed Dependencies

None

This package must remain dependency-free.

## Forbidden Dependencies

- Node.js APIs
- Browser APIs
- React
- NestJS
- Express
- Prisma
- Firebase
- Redis
- BullMQ
- Any other `@nexode/*` package
