# @nexode/events

Shared event contracts for the NeXoDe platform.

## Classification

Foundation Package

## Responsibilities

- Event contracts
- Event interfaces
- Event metadata
- Shared event typing

## Non-Responsibilities

- Event transport
- Queues
- Message brokers
- Event persistence
- Business events

## Public API

```ts
import {} from '@nexode/events';
```

## Allowed Dependencies

- @nexode/types

## Forbidden Dependencies

- React
- NestJS
- Prisma
- Firebase
- Redis
- BullMQ
- Kafka
- RabbitMQ
