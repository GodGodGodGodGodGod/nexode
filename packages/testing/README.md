# @nexode/testing

Shared testing utilities for the NeXoDe platform.

## Classification

Foundation Package

## Responsibilities

- Shared test utilities
- Mock helpers
- Test fixtures
- Test builders

## Non-Responsibilities

- Business tests
- Integration tests
- End-to-end tests

## Public API

```ts
import {} from '@nexode/testing';
```

## Allowed Dependencies

- @nexode/types

## Forbidden Dependencies

- React
- NestJS
- Prisma
- Firebase
- Redis
- BullMQ
