# @nexode/utils

Shared utility functions for the NeXoDe platform.

## Classification

Foundation Package

## Responsibilities

- String helpers
- Array helpers
- Object helpers
- Number helpers
- Date helpers
- Generic utility functions

## Non-Responsibilities

- Business logic
- Authentication
- Logging
- Database access
- Networking
- Cryptography

## Public API

```ts
import {} from '@nexode/utils';
```

## Allowed Dependencies

- @nexode/types

## Forbidden Dependencies

- React
- NestJS
- Prisma
- Firebase
- Redis
- BullMQ
